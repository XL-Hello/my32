# 控制中心 UI 模块说明

## 1. 模块概述

`controlcenter_ui` 是 APP 的独立控制中心页面，源码为 [controlcenter_ui.c](controlcenter_ui.c)，公开入口为 `controlcenter_ui_create()`。页面运行在固定的 `240 × 320 px` 逻辑显示区域（`LCD_H_RES=240`、`LCD_V_RES=320`），坐标原点为屏幕左上角，`X` 向右增加、`Y` 向下增加。

页面提供三项固定入口视觉区：**设备设置**、**网络设置**、**系统信息**。页面不使用 Flex、Grid 或运行时自适应布局；卡片及其子控件均由固定像素坐标、固定像素尺寸和固定资源路径创建。底部手势区的宽度在源码中使用 `LV_PCT(100)`，在固定的 `240 px` 屏幕上解析为 `240 px`。

调用 `controlcenter_ui_create()` 时会先执行 `lv_obj_clean(lv_scr_act())` 清空当前活动屏幕，再一次性创建本页所有对象。模块不创建定时器、不保存页面级对象指针，也不刷新动态数据。

## 3. 三大固定功能分区

三张卡片均为 `lv_obj`，结构固定为“左侧图标容器 + 中间标题 + 右侧箭头”。`s_menu_items` 配置表中每个 item 只保存 `icon_path` 和 `title`；`controlcenter_ui_create_menu_items()` 依次按 `Y=61+索引×76` 计算位置并调用公共的 `controlcenter_ui_create_menu_item()` 创建完整卡片。卡片不注册 `LV_EVENT_CLICKED`、`LV_EVENT_PRESSED` 或页面跳转回调；当前版本的三项内容为固定视觉入口，点击卡片、左图标、文字或右箭头均不会触发设置页面切换。右箭头仅表达入口语义。

## 5. 对接约束与维护要点

1. 修改显示分辨率时，必须同步重新计算本文档中的所有绝对坐标；本模块不具备自动重排能力。
2. 修改卡片高度、图标尺寸或标题字体时，必须同步调整 `CONTROL_CENTER_CARD_ICON_SIZE`、`CONTROL_CENTER_CARD_ICON_X`、`CONTROL_CENTER_CARD_LABEL_X` 及三张卡片的文本和箭头坐标。
3. 三张卡片要接入实际页面时，应在对应卡片对象上注册独立 `LV_EVENT_CLICKED` 回调；不能把回调挂在不可点击的 `lv_img` 图标对象上。
4. 新增或替换 PNG 后必须执行 `./build.sh build flash` 重新生成 `build/littlefs_icons.bin`；仅烧录应用分区不会更新 LittleFS 图标资源。
5. 本模块依赖 PNG 解码和 `R:` 文件系统驱动；资源加载入口为 `ui_icon_set_src()`，资源不可读取时该函数会记录日志并清空图像源。
