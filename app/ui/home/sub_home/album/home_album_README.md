# 首页相册预览模块说明

## 1. 模块概述

`home_album` 是 APP 首页内容区的相册预览 Tab，源码为 [home_album.c](home_album.c)，公开入口为 `home_album_create_tab(lv_obj_t *parent)`。它由 `home_ui` 创建在 `(0, 120)`、`240 × 148 px` 的内容容器内；页面坐标仍以屏幕左上角为基准描述，代码中的子控件坐标则相对于该内容容器。

首页检测到从右向左的横向手势后，仅清空内容容器并创建本 Tab；顶部状态轨道和时间保持原对象、原位置，不会被重建。向右滑动返回首页的温湿度 Tab。本 Tab 只提供一个“相册”入口：点击入口后，必须调用 `album_flash_init()`，由该模块扫描资源、维护图片总数并准备索引 `0` 的当前图片数据；随后将当前图片字节数组、长度和总数传入 `album` 完整相册页。本页不显示、解码、遍历或缓存任何相册图片，不读取 SD 卡，也不直接访问 `photo/` 或 Flash 文件路径。

页面布局以 `UI稿件/05-首页-相册.svg` 与对应尺寸标注稿为实现基线。文档只描述控件、资源和接口约束，不嵌入、列出或引用任何具体相册图片。

### 1.1 全局视觉参数

| 项目 | 固定值 | 实现说明 |
| --- | --- | --- |
| Tab 根控件 | `home_ui` 创建的内容容器 | 位于 `(0, 120)`，尺寸 `240 × 148 px` |
| 背景色 | 继承首页 `#10201F` | Tab 容器透明，不覆盖固定顶部区域 |
| 默认文字字体 | 继承首页 `ui_font_get_16()` | LittleFS 字体 `R:/littlefs/fonts/esp_front_16.bin` |
| Tab 根控件滚动 | 禁用 | 清除 `LV_OBJ_FLAG_SCROLLABLE` |
| 顶部状态轨道 | `(16, 19)`，`208 × 22 px` | 由 `statusbar_ui` 创建并固定保留，不属于本模块 |
| 主交互与图标色 | `#58D6B3` | 相册图标和交互描边 |
| 主文字色 | `#F2FAF7` | “相册”标题 |

### 1.2 图标与相册资源边界

| 用途 | 应用 PNG 源文件 | 运行时路径 | 原始 / 展示尺寸 | 规则 |
| --- | --- | --- | --- | --- |
| 相册入口图标 | `app/ui/icon/png/album.png` | `R:/littlefs/png/album.png` | `24 × 24` / `42 × 42 px` | 透明 PNG、主色重着色；图像对象不可点击 |
| 相册内容 | 不在本模块加载 | 不在本模块读取 | 无 | 点击入口后仅由 `album_flash` 输出图片数组给 `album` |

相册原图的唯一源目录是 `app/ui/home/sub_home/album/photo/`，且只允许目录内的 `*.png` 文件参与 LittleFS 打包。`home_album` 不得扫描该目录、拼接 `R:/littlefs/photo/` 路径、调用 `fopen()`，也不得使用 SD 卡或其他任意文件路径。目录中的非 PNG 文件不是相册资源，必须被打包流程忽略或直接判为错误。

## 2. 首页导航与顶部区域

### 2.1 首页 Tab 切换

| 属性 | 固定参数 |
| --- | --- |
| 手势来源 | 首页内容容器及其可手势冒泡的子控件 |
| 触发事件 | `LV_EVENT_GESTURE` |
| 触发方向 | `LV_DIR_LEFT`，即用户手指从右向左滑动 |
| 执行结果 | 由 `home_ui` 清空内容容器并调用 `home_album_create_tab()`；不得清空当前活动屏幕 |
| 冲突处理 | 首页原有按钮、滑条等独立控件优先处理自己的事件；手势区不得覆盖其点击或拖动命中区 |

进入本 Tab 后，向右横向滑动必须显示首页温湿度 Tab。A01 点击入口仅负责进入完整相册页；首页的横向手势由 `home_ui` 统一处理，避免一次触摸同时触发进入和返回。

### 2.2 顶部状态轨道与时间

| 组件 | 控件类型 | 左上角坐标 | 尺寸 | 固定内容 | 样式与布局 |
| --- | --- | ---: | ---: | --- | --- |
| 状态轨道 | `lv_obj` | `(16, 19)` | `208 × 22 px` | 无 | `#19302E` 背景，圆角 `11 px`，`1 px` 边框 |
| 轨道填充 | `lv_obj` | `(16, 20)` | `174 × 20 px` | 无 | 薄荷绿渐变；仅作首页状态视觉延续 |
| Wi-Fi 图标 | `lv_img` | `(196, 18)` | `24 × 24 px` | 既有 `wifi` 图标 | 主文字色，原始尺寸显示，不可点击 |
| 时间 | `lv_label` | 居中 | 内容尺寸约 `130 × 57 px` | 首页当前时间 | `47 px`、字重 300、主文字色；动态值由首页已有时间服务提供 |

顶部状态轨道和时间均由 `home_ui` 创建并由其定时器刷新；`home_album` 不创建独立的时间服务、定时器或顶部控件。切换 Tab 时不得删除或重建这些对象。

## 3. 相册入口

### 3.1 A01 相册入口

| 组件 | 控件类型 | 左上角坐标 | 尺寸 | 固定内容 | 样式与布局 |
| --- | --- | ---: | ---: | --- | --- |
| A01 命中容器 | `lv_btn` 或可点击 `lv_obj` | `(76, 130)` | `88 × 122 px` | 无 | 透明；覆盖圆形图标、标题和说明；不可滚动 |
| 圆形外环 | `lv_obj` | `(82, 136)` | `76 × 76 px` | 无 | `#173430`，`1 px` 描边，圆形 |
| 圆形内圈 | `lv_obj` | `(91, 145)` | `58 × 58 px` | 无 | `#1C4B43`，圆形 |
| 相册图标 | `lv_img` | `(99, 153)` | `42 × 42 px` | `album.png` | 主色，原图缩放居中，不可点击 |
| 主标题 | `lv_label` | 居中，基线 `Y=232` | 内容尺寸约 `34 × 20 px` | `相册` | `17 px`、字重 600、主文字色 |
| 说明文字 | `lv_label` | 居中，基线 `Y=251` | 内容尺寸约 `90 × 12 px` | 功能说明 | `10 px`、次级文字色 |

A01 收到 `LV_EVENT_CLICKED` 时必须执行以下顺序：

1. 调用 `album_flash_init()`，每次进入完整相册页都重新遍历 `/photo/` 并更新图片总数。
2. 调用 `album_flash_get_image_count()`；模块内部默认将当前索引设为 `0`。
3. 调用 `album_flash_get_current_image()` 取得当前图片的只读字节数组和长度。
4. 调用 `home_ui_destroy()` 停止首页定时器并清除首页对象引用。
5. 调用 `album_create(data, data_len, image_count)` 创建完整相册页。

`album_create()` 的图片数组入参只能来自 `album_flash`。当 `image_count == 0` 时仍进入完整相册页，传入 `NULL`、`0` 和 `0`；页面中央必须显示“空”字，不得伪造、展示或替代为任何相册图片。

## 4. 业务边界与模块划分

模块关系固定如下：

```text
home_ui --左滑 / 切换内容容器--> home_album --点击 A01 / 初始化--> album_flash --当前图片字节数组--> album
                                                               \--总数与当前数据--> 只读 LittleFS /photo/*.png
```

1. `home_ui` 负责固定顶部区域、Tab 容器、两个内容 Tab 的横向切换，以及统一的底部分页指示条和页码。
2. `home_album` 仅负责相册 Tab 的视觉和 A01 入口；它只调用 `album_flash` 的初始化、总数和当前数据接口，不得解析目录、索引或图片文件。
3. `album_flash` 是图片资源的唯一所有者，维护图片总数与当前图片数据，负责 LittleFS 图片遍历、排序、索引读取、数据和长度输出。
4. `album` 仅接收 `album_flash` 输出的当前图片字节数组、数据长度和总数，负责完整浏览页的索引和显示状态。
5. 不允许 `home_ui`、`home_album` 或 `album` 访问 SD 卡、`/sdcard`、`photo/` 源目录、`R:/littlefs/photo/` 路径或任意其他文件系统路径。

## 5. 对接约束与验证

1. 在实现 `home_album.c`、`album.c`、`album_flash.c` 后，必须在 `app/CMakeLists.txt` 的 `SRCS` 中显式加入三份 C 文件，并在 `INCLUDE_DIRS` 中加入 `ui/home/sub_home/album`。
2. 新增“相册”“暂无可用图片”等中文文案时，必须同步更新 `app/ui/front/list_raw.txt` 并重新生成 LittleFS 字体字符列表。
3. 图标资源仍按既有规则打包到 `/png/`；相册内容资源按 [album_flash_README.md](album_flash_README.md) 的规则整体打包到 `/photo/`。两类资源不能混放。
4. 构建后检查：首页左滑仅切换到 `home_album` Tab，顶部状态轨道和时间位置不变；右滑回到温湿度 Tab；点击 A01 时必定先初始化 `album_flash`；有图片时默认显示索引 `0`，无图片时仍进入 `album` 并在中央显示“空”；整个过程中没有直接文件系统访问发生在 UI 层。
5. 运行 `./build.sh build` 验证 C 代码；资源打包实现完成后，运行 `./build.sh build flash` 生成 LittleFS 镜像。真实设备烧录与镜像生成分开执行，未经明确授权不得执行 `./build.sh flash`。
