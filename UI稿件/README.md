# UI 稿件

本目录包含四张 240×320 PNG 效果图和独立 SVG 图标，用于 LVGL 实现参考。

- `01-首页.png`：时间、环境数据、Wi-Fi 和性能状态。
- `02-控制中心.png`：控制中心入口。
- `03-设置.png`：设置列表。
- `04-Wi-Fi设置.png`：重设计后的 Wi-Fi 开关、当前连接与可用网络列表；C01、C02 均为 `46 px` 高，扫描为独立操作区，热点列表为纵向可滑动视窗。
- `04-Wi-Fi设置-尺寸标注.png`：面向开发的全量坐标、尺寸、图标、字号与交互入口标注图。
- `05-首页-相册.png`：从首页向左滑动后的相册功能入口，点击圆形相册图标进入浏览页。
- `05-首页-相册-尺寸标注.png`：相册功能入口的布局、点击区域和首页分页手势标注图。
- `06-相册.png`：相册浏览页，包含返回、标题、图片视窗、左右滑动提示以及当前索引/总数。
- `06-相册-尺寸标注.png`：相册浏览页的控件、图片资源、左右手势与索引规格标注图。

## 墨绿薄荷色板

四张效果图已切换为墨绿薄荷风格。实现时建议固定以下颜色，以保持页面一致：

- 背景：`#10201F`
- 卡片与输入框：`#19302E`
- 主交互、选中态与图标：`#58D6B3`
- 主文字：`#F2FAF7`
- 次级文字：`#9BB9B0`
- 警告/提醒：`#FFC857`

`icons/` 中的图标均为 24×24 SVG，使用 `currentColor` 着色；在设计稿中建议使用主色 `#58D6B3`，次级图标可用 `#9BB9B0`。`back`、`check`、`lock`、`refresh` 及三个 `wifi-signal-*` 图标均提供同名透明 PNG，可直接复制到项目资源目录后按现有 `img_recolor` 规则使用。

Wi-Fi 页面中的交互遵循手机设置逻辑：总开关启停 Wi-Fi；点击“扫描”刷新可用网络；在可用网络列表中纵向滑动浏览全部热点；点击已连接网络进入网络详情（断开/忽略）；点击受保护网络打开密码输入，点击开放网络直接发起连接。

## 相册资源与交互

`icons/album.svg` 是 24×24、使用 `currentColor` 的相册图标；其透明 PNG 同步导出为 `icons/album.png`，在首页相册入口中按 42×42 显示。`photos/` 下提供 3 张 216×192 的示例相册图片，PNG 和 SVG 均已输出，尺寸与浏览页图片视窗一致。

首页从右向左滑动后进入 `05-首页-相册`，点击相册入口进入 `06-相册`。相册浏览页的图片区域支持左滑到下一张、右滑到上一张；处于第一张或最后一张时不循环。底部数字应随当前 `index` 和图片总数更新。
