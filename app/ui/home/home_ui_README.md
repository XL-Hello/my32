# 首页 UI 模块说明

## 1. 模块概述

`home_ui` 是 APP 的首页页面控制器，源码为 [home_ui.c](home_ui.c)，公开接口定义在 [home_ui.h](home_ui.h)。页面运行在固定的 `240 × 320 px` 逻辑显示区域（`LCD_H_RES=240`、`LCD_V_RES=320`）；坐标原点为屏幕左上角，`X` 向右增加、`Y` 向下增加。

首页由三部分组成：顶部状态轨道、当前时间和中部的两个可横向切换 Tab。第一个 Tab 显示温度、湿度、CPU 与 FPS；第二个 Tab 提供相册入口。顶部向下滑动会打开控制中心；在内容区横向滑动可在两个 Tab 间切换。

调用 `home_ui_create()` 会先销毁首页持有的定时器和对象指针，再清空当前活动屏幕并创建全部首页对象，默认显示温湿度 Tab。`home_ui_create_album_tab()` 在此基础上切换到相册 Tab。模块自身不保存屏幕对象指针，但保存时间标签、内容容器、分页控件及时间刷新定时器的指针；离开首页前必须调用 `home_ui_destroy()`。

### 1.1 公开接口与页面关系

| 接口 | 功能 | 调用约束 |
| --- | --- | --- |
| `home_ui_create()` | 重建首页并显示温湿度 Tab | 必须在 LVGL 任务上下文调用 |
| `home_ui_create_album_tab()` | 重建首页后直接显示相册 Tab | 必须在 LVGL 任务上下文调用 |
| `home_ui_destroy()` | 停止首页及温湿度 Tab 的定时器，并清空模块保存的对象指针 | 切换到控制中心、完整相册等其他页面前调用；函数本身不清空屏幕 |

页面关系如下：

```text
                    顶部向下滑动
home_ui ────────────────────────────────> controlcenter_ui
   │                                             │
   │ 首页内容区左滑 / 右滑                         │ 返回按钮或底部上滑
   ▼                                             ▼
温湿度 Tab <─────────────────────────────── home_ui（默认温湿度 Tab）
   │
   └── 左滑 ──> 相册 Tab ── 点击相册入口 ──> album
```

## 2. 顶部固定区域

顶部状态轨道和时间均由首页统一创建，切换温湿度 / 相册 Tab 时不会被删除或重建。

### 2.1 顶部下滑手势区

| 属性 | 固定参数 |
| --- | --- |
| 控件类型 | 透明 `lv_obj`，可点击手势区 |
| 左上角坐标 | `(0, 0)` |
| 尺寸 | `240 × 52 px`；宽度由 `LV_PCT(100)` 在固定屏幕上解析 |
| 视觉样式 | 透明背景、无边框、无内边距、不可滚动 |
| 事件 | `LV_EVENT_GESTURE` |
| 触发条件 | 输入设备存在且手势方向为 `LV_DIR_BOTTOM` |
| 执行结果 | 调用首页注册的回调：`home_ui_destroy()` 后执行 `controlcenter_ui_create()` |
| 手势冒泡 | 清除 `LV_OBJ_FLAG_GESTURE_BUBBLE`，不继续向屏幕父级冒泡 |

### 2.2 状态轨道

状态轨道由 `statusbar_ui_create()` 创建；它是一个初始值为 `100` 的 `lv_slider`，当前不读取 Wi-Fi 连接状态或其他实时数据。滑条保留透明的可拖动旋钮命中区，但不绘制旋钮，以免视觉内容越过 Wi-Fi 分区。

| 组件 | 控件类型 | 左上角坐标 | 尺寸 | 样式 / 状态 |
| --- | --- | ---: | ---: | --- |
| 状态轨道容器 | `lv_obj` | `(16, 18)` | `208 × 24 px` | `#19302E` 背景；`#2A4D47`、`1 px` 边框；圆角 `LV_RADIUS_CIRCLE`；不可滚动 |
| 填充滑条 | `lv_slider` | `(17, 19)` | `173 × 22 px` | 范围 `0–100`、初值 `100`；主区域透明；指示区水平渐变 `#58D6B3` → `#79DCC1`；透明旋钮但保留拖动命中区 |
| 分隔线 | `lv_obj` | `(191, 22)` | `1 × 16 px` | `#2A4D47`，不透明、不可点击、不可滚动 |
| Wi-Fi 图标 | `lv_img` | `(195, 18)` | `24 × 24 px` | `wifi.png`，`#F2FAF7` 重着色，原始尺寸、不可点击 |

滑条自身也监听下滑手势并转发给同一回调；因此用户从顶部空白处或状态轨道区域向下滑动，均可打开控制中心。

### 2.3 当前时间

| 属性 | 固定参数 |
| --- | --- |
| 控件类型 | `lv_label` |
| 初始文案 | `--:--` |
| 内容格式 | 时间有效时为 `HH:MM`；`time()` 不大于 `1700000000` 或本地时间转换失败时保持 `--:--` |
| 对齐方式 | `LV_ALIGN_TOP_MID`，偏移 `(0, 57)`；未显式设置控件尺寸，左右边界随文本字形变化 |
| 字体 / 颜色 | `lv_font_montserrat_48` / `#F2FAF7` |
| 刷新机制 | 创建后立即刷新，并由 `1,000 ms` 周期的 `lv_timer` 刷新 |

## 3. 内容容器与 Tab 导航

首页只重建中部内容容器的子控件来切换 Tab，顶部状态轨道、时间和底部分页控件保持不变。切换前 `home_ui_show_tab()` 会调用 `home_temp_humidity_destroy()`，再执行 `lv_obj_clean(s_tab_content)`，因此温湿度 Tab 创建的定时器不会访问已清除的对象。

### 3.1 内容容器和手势

| 属性 | 固定参数 |
| --- | --- |
| 控件类型 | 透明 `lv_obj` |
| 左上角坐标 | `(0, 120)` |
| 尺寸 | `240 × 148 px` |
| 视觉样式 | 透明背景、无边框、无内边距、不可滚动 |
| 手势事件 | `LV_EVENT_GESTURE`；同时允许子对象通过 `LV_OBJ_FLAG_GESTURE_BUBBLE` 冒泡 |
| 左滑 | `LV_DIR_LEFT` 且当前为温湿度 Tab 时切换至相册 Tab |
| 右滑 | `LV_DIR_RIGHT` 且当前为相册 Tab 时切换至温湿度 Tab |
| 边界行为 | 在首个 Tab 右滑、末个 Tab 左滑均不产生页面变化 |

首页根屏幕也注册同一手势回调。内容容器和温湿度 Tab 的可冒泡子对象可将横向手势传到根屏幕；回调依据当前 Tab 状态判断，单次手势不会造成跨越两个 Tab 的跳转。

### 3.2 分页指示与页码

| 状态 | 第一段 | 第二段 | 页码 |
| --- | --- | --- | --- |
| 温湿度 Tab（`1 / 2`） | `(100, 303)`，`16 × 3 px`，`#58D6B3` | `(124, 303)`，`7 × 3 px`，`#587870` | 右下对齐，偏移 `(-20, -3)` |
| 相册 Tab（`2 / 2`） | `(100, 303)`，`7 × 3 px`，`#587870` | `(112, 303)`，`16 × 3 px`，`#58D6B3` | 右下对齐，偏移 `(-20, -3)` |

两段指示器都是不可点击、不可滚动的 `lv_obj`，圆角为 `LV_RADIUS_CIRCLE`；页码为 `ui_font_get_11()` 的 `lv_label`，文字色为 `#9BB9B0`。页码未设置固定宽高，左边界随 `1 / 2`、`2 / 2` 的实际字形宽度变化。

### 4.2 数据刷新与降级行为

| 数据 | 首次刷新 | 周期 | 数据来源 | 显示规则 |
| --- | --- | ---: | --- | --- |
| 温度、湿度、传感器状态 | 创建 Tab 后立即刷新 | `10,000 ms` | `environment_sensor_get_latest()` | 有效数据按四舍五入保留一位小数，显示为 `<温度> °C` 与 `<湿度> %RH`；更新失败时显示 `Sensor update failed`；无有效数据时显示 `--.- C`、`--.- %RH` 和 `Sensor unavailable` |
| FPS | 创建 Tab 后立即刷新 | `250 ms` | `lv_port_disp_get_refresh_fps()` | 数值与上次显示不同时才更新，格式为 `FPS:05`；数值固定为两位，不足位以 `0` 补足 |
| CPU | 创建 Tab 后立即刷新 | `250 ms` | `cpu_usage_get_percent()` | 数值与上次显示不同时才更新，格式为 `CPU:05%`；数值固定为两位，不足位以 `0` 补足 |

`home_temp_humidity_destroy()` 会删除上述两个定时器并清空所有标签指针。首页切换 Tab 或离开首页时必须通过该接口释放生命周期资源。

## 5. 相册 Tab

相册 Tab 由 [home_album.c](sub_home/album/home_album.c) 实现；首页在左滑后调用 `home_album_create_tab(s_tab_content)`。其入口按钮位于内容容器相对坐标 `(76, 10)`，即屏幕 `(76, 130)`，尺寸为 `88 × 122 px`。按钮透明、无边框、无内边距、不可滚动，并允许手势向首页内容容器冒泡。

| 组件 | 控件类型 | 屏幕左上角坐标 | 尺寸 | 内容 / 样式 |
| --- | --- | ---: | ---: | --- |
| 相册入口命中容器 | `lv_btn` | `(76, 130)` | `88 × 122 px` | 透明；接收 `LV_EVENT_CLICKED` |
| 外环 | `lv_obj` | `(82, 136)` | `76 × 76 px` | `#173430` 背景；`#2A4D47`、`1 px` 描边；圆形、不可点击 |
| 内环 | `lv_obj` | `(91, 145)` | `58 × 58 px` | `#1C4B43` 背景；无边框；圆形、不可点击 |
| 相册图标 | `lv_img` | 图像原点相对入口 `(32, 32)` | 对象 `24 × 24 px`，视觉 `42 × 42 px` | `album.png`；绕中心点 `(12, 12)` 缩放，`img_zoom=448`，抗锯齿，主交互色、不可点击 |
| 标题 | `lv_label` | 入口顶部居中，偏移 `Y=87` | 内容尺寸 | `相册`；`ui_font_get_16()`；主文字色 |
| 说明 | `lv_label` | 入口顶部居中，偏移 `Y=108` | 内容尺寸 | `查看精彩瞬间`；`ui_font_get_11()`；次级文字色 |

点击相册入口时，`home_album_open_event()` 固定按以下顺序执行：

1. 调用 `album_flash_init()` 初始化相册资源；失败时记录错误日志，但仍继续进入完整相册页。
2. 获取 `album_flash_get_image_count()` 和 `album_flash_get_current_image()` 的结果。
3. 调用 `home_ui_destroy()` 停止首页定时器并清空首页对象指针。
4. 调用 `album_create()`，将当前图片数据（或 `NULL`、`0`）及图片数量传入完整相册页。

首页不直接访问相册文件路径或图片数据；资源扫描和数据所有权由 `album_flash` 管理，完整页面由 `album` 管理。详细约束见 [首页相册预览模块说明](sub_home/album/home_album_README.md) 和 [相册资源模块说明](sub_home/album/album_flash_README.md)。

## 6. 生命周期、对接约束与验证

1. `home_ui_create()` 内部会先调用 `home_ui_destroy()`，随后清空 `lv_scr_act()`。不要在首页仍可见时从外部重复创建时间定时器或温湿度 Tab 定时器。
2. 从首页进入控制中心时，必须先调用 `home_ui_destroy()`，再调用 `controlcenter_ui_create()`；控制中心返回使用 `home_ui_create()`，因此会恢复默认温湿度 Tab。若需从其他页面直接回到相册 Tab，应调用 `home_ui_create_album_tab()`。
3. 首页内容区使用固定像素坐标，不使用 Flex、Grid 或运行时自适应布局。修改 `HOME_UI_TAB_CONTENT_Y`、内容高度、状态轨道尺寸、图标尺寸或字体时，必须同步复核本文档中的屏幕坐标、手势命中区与分页位置。
4. 图像对象均不可点击；相册交互必须注册在入口 `lv_btn` 上。温湿度行、活动图标底座和相册入口保留手势冒泡，不能在其上清除 `LV_OBJ_FLAG_GESTURE_BUBBLE`，否则横向 Tab 切换可能失效。
5. 新增中文文案时更新 `app/ui/front/list_raw.txt`；新增首页 PNG 时放入 `app/ui/icon/png/`、在 `icon.h` 增加路径宏，并通过 `ui_icon_set_src()` 加载。随后执行 `./build.sh build flash` 重新生成 `build/littlefs_icons.bin`。该命令生成资源镜像，不等同于物理烧录。
6. 代码修改后运行 `./build.sh build`；设备验证至少覆盖：无有效时间时的 `--:--`、顶部下滑进入控制中心、温湿度 / 相册双向切换、分页与页码同步、传感器可用和不可用显示、CPU/FPS 刷新、相册入口以及返回首页后的定时器恢复。
