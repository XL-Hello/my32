# 相册完整页面模块说明

## 1. 模块概述

`album` 是点击首页相册预览页 A01 后进入的完整相册浏览页面，源码为 [album.c](album.c)，公开入口建议为 `album_create()`。页面运行在固定的 `240 × 320 px` 逻辑显示区域（`LCD_H_RES=240`、`LCD_V_RES=320`），坐标原点为屏幕左上角，`X` 向右增加、`Y` 向下增加。

页面由顶部返回按钮与标题、P01 图片显示视窗、左右切换手势提示和 I01 当前索引/总数构成。视觉布局以 `UI稿件/06-相册.svg` 与对应尺寸标注稿为实现基线。本文不嵌入、列出、命名或引用任何具体相册图片；相册内容仅作为 `album_flash` 输出的通用数据项处理。

`album` 是纯上层业务与 LVGL 页面模块：不遍历 Flash、不解析目录、不拼接图片路径、不读取 SD 卡，也不访问 `photo/` 源目录。所有图片显示和切换函数的输入参数必须是 `album_flash` 输出的当前图片字节数组及其长度；页面创建时另接收由 `album_flash` 维护的图片总数。

### 1.1 全局视觉参数

| 项目 | 固定值 | 实现说明 |
| --- | --- | --- |
| 页面根控件 | 当前活动屏幕 `lv_scr_act()` | 尺寸由显示驱动固定为 `240 × 320 px` |
| 背景色 | `#10201F` | 不透明，`LV_OPA_COVER` |
| 默认标题字体 | `ui_font_get_16()` | LittleFS 字体 `R:/littlefs/fonts/esp_front_16.bin` |
| 根控件滚动 | 禁用 | 清除 `LV_OBJ_FLAG_SCROLLABLE` |
| 主交互色 | `#58D6B3` | 返回按钮描边、图片框高光 |
| 主文字色 | `#F2FAF7` | 页面标题、索引数字 |
| 次级文字色 | `#9BB9B0` | 手势说明 |
| 图片框底色 | `#17302E` → `#20423D` | P01 图片未就绪时的占位底板；不得以示例图片替代 |

### 1.2 图片数据来源与显示约束

| 用途 | 数据来源 | 上层取得方式 | 运行时位置 | 约束 |
| --- | --- | --- | --- | --- |
| P01 当前图片 | `album_flash` 输出的当前图片字节数组 | `album_create(data, data_len, image_count)` 传入；每次切换都将新数组和长度传入显示函数 | `album_flash` 内部管理的 LittleFS `/photo/` 资源 | `album` 不打开文件、不遍历目录、不持有可写图片数据 |
| 图片总数 | `album_flash_get_image_count()` | 页面创建时作为 `image_count` 传入 | 无 | 计数为 0 时进入空状态，中央显示“空”字 |
| 返回图标 | 既有透明 PNG | `ui_icon_set_src()` 或等效统一图标接口 | `R:/littlefs/png/back.png` | `24 × 24 px`，主色重着色，不可点击 |

相册原图唯一允许来自 `app/ui/home/sub_home/album/photo/` 的 PNG 文件，并由打包流程写入 LittleFS `/photo/`。`album` 不得读取该目录、不得从 SD 卡加载、不得接受任意路径字符串作为图片来源，也不得将 UI 稿件中的示意图片放入代码或文档。

H01 的点击事件必须挂在按钮容器，而不是 `lv_img`。返回时先销毁本页 LVGL 对象并清空所有对当前图片数据的引用，再调用 `album_flash_deinit()` 释放模块堆内存，最后调用 `home_ui_create_album_tab()` 重新创建固定顶部区域并显示相册 Tab；不得重新扫描 Flash 或让已释放的数据继续作为图像源。

## 3. P01 图片显示与切换

### 3.1 P01 图片视窗

| 组件 | 控件类型 | 左上角坐标 | 尺寸 | 数据 / 样式 | 交互 |
| --- | --- | ---: | ---: | --- | --- |
| P01 视窗底板 | `lv_obj` | `(12, 56)` | `216 × 192 px` | 圆角 `9 px`；深色渐变底板；无图片时保留空状态，不得展示示例图 | 监听横向手势 |
| P01 图片对象 | `lv_img` 或统一图片显示控件 | `(12, 56)` | `216 × 192 px` | 源自当前 `data[0..data_len-1]`；等比裁切填充；边框内居中 | 不可直接点击 |
| P01 高光边框 | `lv_obj` | `(12, 56)` | `216 × 192 px` | `1 px`、主色低透明度、圆角 `9 px` | 不可点击 |
| B01 前一张提示 | `lv_obj` + 图标 | `(13, 138)` | `28 × 28 px` | 半透明圆形底座；只作辅助提示 | 可选点击，等价于右滑 |
| B02 后一张提示 | `lv_obj` + 图标 | `(199, 138)` | `28 × 28 px` | 半透明圆形底座；只作辅助提示 | 可选点击，等价于左滑 |

P01 的图片对象只消费 `album_flash` 提供的 `data` 与 `data_len`。`album` 只读使用该图片字节数组，不得释放、修改、缓存底层文件句柄或从路径重新读取。切换前必须先清空 P01 的旧图像源，再请求下一项；图片显示失败时保持底板与错误状态，不得回退读取其他路径。

### 3.2 G01 左右滑动规则

| 属性 | 固定参数 |
| --- | --- |
| 手势区 | P01 `(12, 56)`，`216 × 192 px` |
| 事件 | `LV_EVENT_GESTURE` |
| 左滑 | 当 `index + 1 < image_count` 时，显示下一项并令 `index += 1` |
| 右滑 | 当 `index > 0` 时，显示上一项并令 `index -= 1` |
| 边界 | 不循环；首项继续右滑、末项继续左滑均保持当前项 |
| 最小有效位移 | 建议 `24 px`；低于阈值不切换 |
| 事件竞争 | 图片手势与 H01、B01、B02 事件隔离；不得由透明覆盖层吞掉返回点击 |

页面内部索引以 `0` 为首项；I01 显示值使用 `index + 1`。图片切换必须同时更新 P01 图片、I01 文本以及 B01/B02 可用状态。计算出有效目标索引后，`album` 必须先清空 P01 的旧图像源，再调用 `album_flash_get_image_by_index()`；该接口先释放前一张图片数据，随后加载目标项并输出新的当前图片数据。不得重新扫描目录、读取文件、解析路径或访问 SD 卡。

建议将切换逻辑约束为以下形式，所有参数由调用方提供：

```c
static bool album_show_image(const uint8_t *data,
                             size_t data_len,
                             size_t index,
                             size_t image_count);
```

`data` 必须是 `album_flash_get_current_image()` 或 `album_flash_get_image_by_index()` 输出的只读图片字节数组，`data_len` 必须与同一次输出的数据匹配。调用前旧图像源已被清空，因此当底层加载失败时函数必须维持空状态；不能接受路径字符串、文件句柄或 SD 卡数据作为替代入参。

### 3.3 I01 索引 / 总数与空状态

| 组件 | 控件类型 | 左上角坐标 | 尺寸 | 固定样式 |
| --- | --- | ---: | ---: | --- |
| 手势说明 | `lv_label` | 居中，基线 `Y=270` | 内容尺寸约 `100 × 12 px` | `10 px`、次级文字色；说明左右滑动 |
| I01 底板 | `lv_obj` | `(92, 281)` | `56 × 25 px` | `#193631`，`0.8 px` 描边，圆角 `12.5 px` |
| I01 数字 | `lv_label` | 居中 | 内容尺寸约 `24 × 14 px` | `12 px`、字重 600、主文字色；斜杠为次级色 |

当 `image_count > 0` 时，I01 按“当前项 / 总数”显示。`image_count == 0` 时不创建可切换图片对象，B01/B02 禁用，P01 中心 `(120, 152)` 创建一个 `lv_label` 显示固定文案“空”；I01 显示空状态。不得构造 `1 / 1` 或放入任何样例图片以掩盖空资源。

## 4. 业务接口与职责边界

完整相册页的创建入口建议如下：

```c
void album_create(const uint8_t *data, size_t data_len, size_t image_count);
```

调用方为 `home_album`：先调用 `album_flash_init()`，再读取图片总数与索引 `0` 的当前图片数据，并将 `data`、`data_len`、`image_count` 原样传入 `album_create()`。`album_create()` 初始化内部索引为 `0`；每次切换时由 `album_flash_get_image_by_index()` 更新当前数据，再将返回的图片数组和长度传给页面内部显示函数。

| 模块 | 允许职责 | 禁止职责 |
| --- | --- | --- |
| `home_album` | 进入完整相册前初始化并传递当前数据、长度、总数 | 解析图片、遍历 Flash、按路径读文件 |
| `album` | 页面对象、索引、手势、显示状态、返回 | Flash 遍历、索引映射、文件读取、SD 卡访问 |
| `album_flash` | PNG 资源打包后的枚举、总数、当前数据、索引读取和数据/长度输出 | 创建 LVGL 控件、处理页面手势 |

后续缩略图、预加载、图片格式校验、缓存和解码策略都必须先在 `album_flash.*` 扩展；上层 `album.c` 的当前图片数组入参与页面切换规则保持不变。

## 5. 字体、资源打包与验证

1. 新增或修改本页中文文案后，必须同步更新 `app/ui/front/list_raw.txt` 并执行 `python3 app/ui/front/generate_font_list.py`。
2. 相册图片只允许来自 `app/ui/home/sub_home/album/photo/*.png`，构建时整体复制到 LittleFS 镜像的 `/photo/`；不得把图片放入 `app/ui/icon/png/`，也不得在本模块维护单张图片列表。
3. `album_flash.*` 实现与 `album.c` 实现完成后，必须在 `app/CMakeLists.txt` 注册它们；资源打包脚本也必须将 `photo/*.png` 写入 staging 目录的 `photo/` 子目录。
4. 运行 `./build.sh build` 验证 C 代码；运行 `./build.sh build flash` 生成 LittleFS 镜像。生成镜像不等同于物理烧录，未经明确授权不得执行 `./build.sh flash`。
5. 目标设备验证应覆盖：从 A01 进入时初始化、默认索引 `0`、H01 返回时反初始化、第一项右滑边界、最后项左滑边界、B01/B02 状态、I01 更新、P01 中央“空”状态，以及 UI 层不存在直接 Flash/SD 卡文件访问。
