# UI 稿件

本目录包含四张 240×320 PNG 效果图和独立 SVG 图标，用于 LVGL 实现参考。

- `01-首页.png`：时间、环境数据、Wi-Fi 和性能状态。
- `02-控制中心.png`：控制中心入口。
- `03-设置.png`：设置列表。
- `04-Wi-Fi设置.png`：Wi-Fi 开关、扫描、网络选择和连接操作。

## 墨绿薄荷色板

四张效果图已切换为墨绿薄荷风格。实现时建议固定以下颜色，以保持页面一致：

- 背景：`#10201F`
- 卡片与输入框：`#19302E`
- 主交互、选中态与图标：`#58D6B3`
- 主文字：`#F2FAF7`
- 次级文字：`#9BB9B0`
- 警告/提醒：`#FFC857`

`icons/` 中的图标均为 24×24 SVG，使用 `currentColor` 着色；在设计稿中建议使用主色 `#58D6B3`，次级图标可用 `#9BB9B0`。导入 LVGL 前请通过项目所用的图片转换工具转换为目标色深和格式。
